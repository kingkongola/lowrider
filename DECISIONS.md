# Decisions

Record settled choices separately from hypotheses. Change these when a later decision supersedes them.

## D001 — Build LowRider V4
**Status:** decided / parts purchased

PrintNC was attractive for stiffness and aluminium but was too expensive for the current budget and represented a significantly larger machine-building project before reaching useful output. LowRider gets useful capability sooner and is better aligned with large sheet/furniture/workshop jobs.

## D002 — PrintNC and LR4 are not the same tool
**Status:** decided

Do not judge the LR4 solely as a cheaper PrintNC. LR4's advantage is large-area routing at low cost. A future PrintNC could coexist as a smaller, stiffer metal-focused machine.

Consequence: avoid expensive LR4 modifications whose main purpose is to imitate PrintNC rigidity.

## D003 — Working area about 650 × 1200 mm
**Status:** latest accepted target; exact build dimensions still need freezing

650 × 1200 mm was explicitly accepted as a sensible size. An earlier/later conversational shorthand of 650 × 1250 also appeared, so use the official calculator before any irreversible size-dependent cuts and record the final number here.

Reasoning: large enough for many useful CNC parts while avoiding a huge permanent machine just to process full-size sheet goods. Long/simple furniture panels can be cut with a circular saw + guide/track; CNC tiling remains possible when genuinely useful.

## D004 — Large sheet cutting does not dictate CNC size
**Status:** decided

Do not make the LR4 2.5 m long merely to cut wardrobe sides/full sheets. Straight cuts on large sheets are better handled with the existing circular saw plus a good guide jig/track, with a plunge/track saw as a possible later convenience purchase.

## D005 — Router table indoors; plasma table separate outdoors
**Status:** decided

Do not build an integrated plasma/router water-table compromise into the indoor LR4 table.

If plasma CNC is pursued later:
- separate outdoor plasma table
- LowRider gantry can be carried/moved to it
- copy compatible X geometry / Y rails / belt mounts where practical
- removable torch mount
- blowback-start plasma preferred for CNC
- start without THC; add torch-height control only if actual use requires it

## D006 — Standard LR4 first
**Status:** decided

Build standard/near-standard LR4 properly before performance modifications. Table quality, correct assembly, extraction and workflow matter before speculative stiffness upgrades.

## D007 — Aluminium is secondary capability
**Status:** decided

The LR4 should be capable of useful light aluminium work with suitable tooling, shallow engagement and sensible parameters. It is not being purchased as a high-MRR aluminium mill. A future repeated need for demanding aluminium work is evidence for a stiffer second machine rather than automatic justification for modifying everything now.

## D008 — Furniture / built-ins are valid use cases
**Status:** decided

Use CNC for the operations where CNC adds leverage: repeatability, holes, hinge locations, dados/grooves, pockets, curves, fronts, templates/jigs and special parts. Use a saw/guide for trivial long straight cuts outside the work envelope.

## D009 — Keep the project Pareto-oriented
**Status:** decided

The machine is a force multiplier for other projects, not an end in itself. Prefer the shortest safe path to a calibrated, usable CNC over optional complexity.
